# Registro de decisões

A reunião pode produzir registros de decisão (ADRs adaptados à governança).

## Modelo

```markdown
# DEC-0001 — Título

- Data:
- Status: proposta | aprovada | rejeitada | substituída
- Participantes da discussão:
- Autoridade responsável pela aprovação:
- Issue/PR:
- Contexto:
- Opções consideradas:
- Decisão:
- Justificativa:
- Impactos e próximos passos:
```

Nenhuma decisão deve ser marcada como **aprovada** apenas porque um PR foi aceito: registrar explicitamente a instância institucional competente quando o assunto for institucional.
